# Python Practice Projects

This repository contains a collection of Python projects focusing on data analysis, web scraping, and practical programming tasks. Each project demonstrates different Python programming concepts and real-world applications.

## 🗂️ Project Contents

### Web Scraping Projects
- **2-Web Scraping.ipynb**: General web scraping techniques and implementations
- **Youtube_scraping (1).ipynb**: Specific implementation for scraping YouTube data

### Data Analysis Projects
- **CO2 and Temperature.ipynb**: Analysis of CO2 emissions and temperature data
- **Titanic.py**: Analysis of the famous Titanic dataset
- **temperature_gaz_dataset.xlsx**: Supporting dataset for CO2 and temperature analysis

### Utility Projects
- **To_do_list_manager_Task.ipynb**: Implementation of a task management system

## 🚀 Getting Started

### Prerequisites
- Python 3.x
- Jupyter Notebook
- Required Python packages (install via pip):
  ```bash
  pip install pandas numpy matplotlib jupyter beautifulsoup4 requests
  ```

## 📚 Project Descriptions

### Web Scraping
- Learn how to extract data from websites using Python
- Implement YouTube data extraction techniques
- Practice with BeautifulSoup and requests libraries

### Data Analysis
- Analyze historical CO2 emissions and temperature trends
- Explore the Titanic dataset using Python data analysis tools
- Visualize data using matplotlib and other plotting libraries

### Task Management
- Create and manage to-do lists using Python
- Practice object-oriented programming concepts
- Implement file handling and data persistence
